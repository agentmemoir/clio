# Item Read

## When to use

Read, inspect or summarize stored items.

## Tools

`get`, `get_snapshot`, `get_gist`, `inspect`, `audit_trail`, `summarize`, `consolidate`, `maintenance_status`, `canonical_get`, `shared_retrieve`, `scratchpad_read`

## Examples

```
get({"item_id": "demo-note"})
inspect({})
```

## Exact arguments

Call `tool_describe` with a tool name from the list above for the exact arguments. For example: `tool_describe("get")`.
