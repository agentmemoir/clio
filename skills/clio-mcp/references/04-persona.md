# Persona

## When to use

Read or record stable preferences.

## Tools

`persona_get`, `persona_put_stable`, `persona_observe_preference`

## Examples

```
persona_get({})
persona_observe_preference({"key": "brevity_affinity", "observed_value": 0.6})
```

## Exact arguments

Call `tool_describe` with a tool name from the list above for the exact arguments. For example: `tool_describe("persona_get")`.
