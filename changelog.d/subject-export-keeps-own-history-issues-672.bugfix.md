A one-subject export now reads the subject's own task and failure history instead of the bank's newest rows. Before this change the subject export took the bank's most recent 10,000 task rows and 10,000 failure rows and then kept the subject's rows, so a busy bank could drop every one of the subject's own tasks and failures from the delivered file, and the manifest claimed the history was truncated. The row cap now counts the subject's own rows, so those records are delivered and the truncation note appears only when the subject itself exceeds the cap. The whole-bank export is unchanged and still reads the bank's newest rows, because a bank-wide export is meant to describe the whole bank.
