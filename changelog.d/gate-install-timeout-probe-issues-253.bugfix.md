The `gate-install.sh` installer now finds the timeout tool under both names, `timeout` and `gtimeout`, so a macOS host with GNU coreutils installed no longer reads its own shim as unverifiable and no longer fails the install with "profile verification is unavailable"; when neither tool is present the message names both names and says how to get one.
