The MCP `import_provider` tool now requires an administrative caller, as the `import` tool already did: an agent or user credential is refused with `forbidden` before any argument is read. Previously anyone holding an agent or user credential could point the provider ingest at a base URL of their choosing and have the server fetch it while sending the server-side Mem0 API key in the authorization header, which leaked that key and let the caller use the server as a request proxy.
