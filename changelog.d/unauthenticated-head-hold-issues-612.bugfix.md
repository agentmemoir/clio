An unauthenticated client that sends only part of an HTTP request head no longer holds one of the MCP transport's 32 connection slots for the full 30 s total deadline: the head now has its own 2 s read budget, configurable through `HttpConfig::head_deadline_secs` and clamped to the total, and a head that misses it is refused with a 408 that names the bound. [Issue #612](https://github.com/agentmemoir/clio/issues/612)
