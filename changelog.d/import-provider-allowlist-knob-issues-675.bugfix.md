The MCP `import_provider` tool now refuses any `api_base_url` whose host the operator allowlist does not name, and the shipped allowlist contains only `api.mem0.ai`, so an operator pointing the import at a self-hosted or proxied Mem0 endpoint gets a hard `forbidden` refusal where it used to work: set `provider.allow_hosts` (or the comma-separated environment variable `CLIO_PROVIDER_ALLOW_HOSTS`) to the endpoint's host to allow it, and note that `credentials_masked` now reports no server API key for an endpoint the allowlist does not name.
