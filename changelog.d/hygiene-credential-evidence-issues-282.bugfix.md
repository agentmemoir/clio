`clio hygiene audit` no longer reports ordinary records whose ids happen to contain a long hyphenated run as secret credentials: a record is flagged only when it carries a named credential key, a private-key marker, a bearer token, or a known credential prefix, genuine credentials are scored by evidence kind and run length, and a token-shaped run seen only through the broad proxy pattern now lands in the lower `flag` band with a readable masked preview instead of a redacted one and a `discard` recommendation.
