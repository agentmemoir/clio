`clio ops reindex --confirm` now performs the live rebuild it always claimed to: `--confirm` alone is the live switch on the CLI and over MCP, `--dry-run` is the report-only switch, and asking for both is refused. A report-only reindex applies nothing, reports `ok: false`, and now exits 3 where it previously exited 0, so an explicit report-only run is a deliberate exit-code change; `--dry-run false` is no longer the documented way to go live.
