A backup prune now resolves the backup directory once per run and unlinks only the file name joined to that resolved directory, so a local user with write access to the backup directory can no longer use a symbolic link or a `..`-bearing path to make Clio delete a file outside it: before this change containment was decided by comparing path spelling alone, and a backup directory that could not be resolved fell back to the raw path. A candidate whose parent no longer resolves to that directory is now reported as outside the backup directory, and a backup directory that cannot be resolved at all is reported and removes nothing.
