The key material behind at-rest encryption no longer leaves a copy behind in memory after use. The data encryption key and the blind-index key were handled as plain fixed-size byte arrays, which are copied implicitly whenever they are returned or passed on, so those copies outlived the wipe that runs when the original key slot is dropped. Both keys now stay inside wrappers that wipe their contents on drop, and every accessor that hands a key out returns that wrapper instead of the raw array, so a caller cannot keep a stray plaintext copy. Behaviour is unchanged for a reader of the store: existing key slots, envelopes, and blind indexes keep working, and no data has to be re-keyed or migrated.
