The data encryption key and the blind-index key now stay in wrappers that wipe their contents on drop, and the accessors that hand a key out return those wrappers instead of a plain fixed-size array, so a caller no longer keeps a stray plaintext copy; the AEAD cipher is built with its `zeroize` feature so the key copy it holds is wiped when the cipher is dropped. Behaviour is unchanged for a reader of the store: existing key slots, envelopes, and blind indexes keep working, and no data has to be re-keyed or migrated.
