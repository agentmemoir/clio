The eight page commands — `recall`, `inspect`, `triple query`, `task history`, `failure list`, `memtree query`, `hygiene audit`, and `hygiene log` — now apply one page-size rule: `--limit 0` is refused with a usage error, a limit above 200 is served as 200 instead of being refused or silently lowered, and the served page names the value the caller asked for in both JSON and text output. Each command's `--help` now names its default page size and the 200 ceiling, so a caller no longer has to probe the tool to learn either number. `hygiene audit` in particular now succeeds with an above-cap limit instead of exiting with an out-of-range error, and `memtree query` no longer serves more than 200 nodes per page. `triple query` gains `--offset` alongside the rule: it pages with `--limit` and `--offset`, defaults to 50 rows per page capped at 200, echoes the served `limit`/`offset` and the full match count with a `truncated` marker in JSON output, and shows `triples: N of M` in text output.
