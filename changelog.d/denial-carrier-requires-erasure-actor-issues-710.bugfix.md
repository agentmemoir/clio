A sync push can now record an erasure denial only when the presented token's actor is `harness` or `system`. Before this change, any bank-scoped token could durably refuse an arbitrary subject for every bank on the node, and that refusal could not be removed. A node that delivers denials to a peer must present a token created with `clio auth token add --actor harness` (or `system`); a carrier from a token with another actor is rejected and quarantined in the dead-letter queue, and the node records no subject denial and no bank marker.
