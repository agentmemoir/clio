Export staging directories in the system temp folder are now created owner-only (mode 0o700) with an unpredictable per-run name, so another local user can neither read staged export bytes nor plant files where delivery will write. Delivery refuses — with a clear error — any existing directory at a staging path that is not owned by the current user with owner-only permissions; an attacker-created link or wide-permission directory can no longer be silently reused. A staging directory left by an older version with broader permissions must be removed once before export works again.
