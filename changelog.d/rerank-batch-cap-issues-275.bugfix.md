The TEI reranker's documents-per-request cap is now configurable as `rerank.max_batch` (`CLIO_RERANK_MAX_BATCH`, settable through `config_set` and bounded to 1..=1000, with a value of 0 or a non-number falling back to the 32-document default); it applies to the TEI reranker only, the Cohere provider ignores it, and the value must not exceed the rerank service's `--max-client-batch-size` ceiling — set the client cap and the sidecar ceiling together, or the service answers a too-large batch with a request error instead of reranking.
