An older database whose `local_events` table still held only the placeholder `id` column now converges onto exactly the event columns the current schema declares, on both SQLite and Postgres: the legacy key is dropped, the SQLite table is rebuilt under one write transaction, and both unique guarantees are restored. Local-event writes and reads work again, and a backup of the repaired store restores into a fresh database. [Issue #238](https://github.com/agentmemoir/clio/issues/238)
