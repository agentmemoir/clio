An older database whose `local_events`, `copy_inventory`, or `durable_requests` table still held only the placeholder `id` column now converges onto exactly the columns the current schema declares, on both SQLite and Postgres: the legacy key is dropped, the SQLite table is rebuilt under one write transaction, and the unique guarantees are restored. Local-event, copy-inventory, and durable-request writes and reads work again, and a backup of the repaired store restores into a fresh database.
