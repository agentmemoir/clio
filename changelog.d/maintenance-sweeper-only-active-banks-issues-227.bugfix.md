An idle `clio mcp` server no longer polls every bank in the store on its five-second maintenance tick: the background trigger now evaluates only banks the session has resolved, the configured default bank, and the shared bank, so an idle server stays quiet on a store with thousands of banks instead of issuing a burst of `assoc_edges` and `distilled_units` queries per tick.
