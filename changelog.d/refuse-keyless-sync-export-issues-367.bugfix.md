The sync client library no longer exports memory in the clear: `clio_sync::client::push` fails on a node that holds no sync key with a configuration error naming the missing key and the `clio sync keygen` remedy, where it used to package the bank's record content as plaintext for the wire. The `clio sync push` command already refused keyless transfers through its custody check before this change, so what changes here is the library entry point that embedders call directly, not the command. `sync status` on such a node still reports `encryption: false` without an error, a push from a node holding a key is unchanged, and a keyless push with no pending rows still completes with a cursor.
