The `embed`, `rerank`, and `extract` sidecars in `compose.yml` now publish their host ports on `127.0.0.1` only, the same way the managed Postgres port already did: a bare `PORT:CONTAINER` mapping was shorthand for `0.0.0.0`, and none of the three has authentication, so anyone on the same network could call the retrieval and extraction endpoints, read whatever text they posted, and spend this host's CPU reranking it. Nothing changes for a client on the host, because `.env.example` already points `CLIO_EMBED_URL`, `CLIO_RERANK_URL`, and `CLIO_EXTRACT_URL` at `127.0.0.1`. A client on another machine that relied on the old reachable port has to forward it over SSH or publish it at an address of its own.
