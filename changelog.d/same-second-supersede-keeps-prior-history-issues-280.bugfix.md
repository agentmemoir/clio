Superseding a fact in the same second it was asserted now closes the replaced row one second later than its own start instead of inside its own second, so the earlier assertion stays readable in transaction-time history rather than disappearing. A supersede stamped later than the row's start is written exactly as given, and rows already stored are unchanged. A row closed in the same second as it was asserted now stays readable for that closing second, alongside the successor that replaced it.
