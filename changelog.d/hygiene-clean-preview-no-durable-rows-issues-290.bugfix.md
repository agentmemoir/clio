The `hygiene clean` preview no longer writes durable hygiene-log rows, so its zero-writes promise now matches what it actually does. The preview also no longer reports actions for items already discarded or archived; it reports what would happen only for targets that still need it. The `would_flag`/`would_archive`/`would_discard` counters now carry one meaning in every `hygiene clean` response: on a confirmed run each equals the applied count for its action, matching the preview count. A confirmed `hygiene clean` now records the supplied `reason` and `note` in each durable log row's detail, so the audit row shows why the action was taken.
