Postgres-backed tests no longer pass when the database cannot be opened: across clio-store, clio-compliance, clio-history, clio-retrieve, and the clio command harnesses, an unreachable Postgres now fails the run instead of printing a skip note and returning, so a green suite proves the Postgres path actually ran, and a redacted harness message no longer prints the connection string. Set `CLIO_SKIP_PG_TESTS` to `1`, `true`, or `yes` to opt out deliberately.
