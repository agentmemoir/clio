The `gate-install.sh` installer now treats the shim as active when a login shell or an interactive shell resolves it, so a plain `ssh` install on a correctly set up machine no longer fails; it accepts a shim only when a shell resolves a symlink that points at the installed shim, names a login/interactive divergence instead of hiding it, and reads a probe that outlasts its 5s budget as unknown rather than as inactive.
