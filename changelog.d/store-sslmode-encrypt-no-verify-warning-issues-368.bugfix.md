Opening the Postgres store with `sslmode=encrypt-no-verify` now logs a startup warning saying that the connection is encrypted but the server certificate is not validated, so any host that can intercept it can impersonate the database, and names `sslmode=verify-full` with `sslrootcert=PATH` as the safe alternative.
