The generated Markdown manual checked every `--out` path component and then resolved the path again to create the directory and write each page, so a component swapped for a symlink after the check could redirect generated pages into the linked directory; the output directory is now opened once and held, and every later step — the target check, the temp file, its mode and sync, and the rename — is performed inside that held directory, so a swapped component refuses the write instead of redirecting it.
