A backup that carries its key store and was taken from a store after an erasure now restores: the restore authority check refuses an archive only when it still carries usable key material for a denied subject, so a backup that keeps just the erased subject's destroyed key slot, tombstone, or ciphertext-only row loads back while the erased content stays unreadable; a backup that omits its key store still refuses such a reference, because the restore leaves the target's key store in place and cannot prove the reference unreadable.
