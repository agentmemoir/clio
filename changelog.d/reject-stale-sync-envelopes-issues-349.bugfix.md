A sync envelope is now refused as stale when its authenticated `transaction_time` sits further from the applying node's clock than the freshness window allows, in either direction, so a stamp the node cannot place is no longer applied. The refusal reports `stale`, writes nothing, and advances the pull cursor past the row instead of freezing that bank; a window of `0` turns the rule off, and every shipped caller leaves it off today, so the observable behaviour of a default node is unchanged until a caller passes a window.
