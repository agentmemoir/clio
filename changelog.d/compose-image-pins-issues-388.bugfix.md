The TEI embedding and rerank images are pinned to `cpu-1.9.4` on amd64 and `cpu-arm64-1.9.4` on arm64, the local NuExtract extract server image is pinned to llama.cpp build `server-b12033`, and CI now runs `pgvector/pgvector:0.8.6-pg16` instead of the floating `pg16` tag, because that is the tag the compose stack ships and tests and local runs should share one database build. An existing `.env` copied from an older `.env.example` still sets `CLIO_TEI_IMAGE` or `CLIO_LLAMA_CPP_IMAGE`, and a value in `.env` overrides the compose default, so update both names to the pinned values above or the older tag stays in use.
