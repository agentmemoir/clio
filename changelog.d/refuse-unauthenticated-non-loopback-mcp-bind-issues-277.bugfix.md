`clio mcp http` no longer serves without authentication on a non-loopback address: a bind outside loopback with no `--token-file` is refused at start unless `--insecure-no-auth` is paired with the new `--insecure-bind-any` flag, so the one opt-out that was meant for local development can no longer widen the listener to every interface by itself. That pairing starts the server and prints a warning that any host able to reach the port can use every tool on every bank the server exposes. The help text for `--bind`, `--insecure-no-auth`, and the new flag now says so. [Issue #277](https://github.com/agentmemoir/clio/issues/277)
