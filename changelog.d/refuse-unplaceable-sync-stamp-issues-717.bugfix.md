A peer could send a sync write whose `transaction_time` is not a timestamp and win last writer wins, because the freshness refusal returned before it tested whether the stamp could be placed and the comparator then fell back to byte order; an unplaceable stamp is now refused at every freshness window, including the default `0`, so such a write is reported as malformed instead of replacing the stored row, and a mutation's own payload `updated_at` is validated before it is stored, so a junk payload stamp can no longer become the stored side of a later comparison and freeze the item.
