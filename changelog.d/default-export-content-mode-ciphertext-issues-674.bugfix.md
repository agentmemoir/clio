An export made without `--content-mode` now writes the opaque `ciphertext_backup` bundle, so the default export never carries readable memory content; a readable DSAR bundle needs `--content-mode dsar_plaintext`, the explicit readable export opt-in, and a base64-encoded 32-byte X25519 public key of the recipient, and the bundle is sealed to that key, so only the matching secret key opens it while Clio never holds it.
