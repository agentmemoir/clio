The two free-space checks — the gate a backup verify pass runs before it stages its payload, and the restore pre-flight — now open the `df` they found once, judge that open file rather than the path, and execute the very same file, so replacing the `df` path between the check and the run can no longer make Clio run a different program; a host where an open file cannot be executed instead answers from its file-system statistics and runs nothing.
