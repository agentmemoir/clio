The dev image now builds from a digest-pinned Ubuntu 24.04 base rather than the floating `ubuntu:24.04` tag, and fetches its rustup bootstrap installer from a version-pinned URL, checking it against the SHA-256 that URL publishes before it runs, instead of piping the remote `https://sh.rustup.rs` script into `sh`. That check covers the bootstrap installer only: the rustc and cargo payload rustup then downloads is fetched over TLS and is not hash-verified here.
