Replaced the unmaintained `chrono` dependency with `jiff` 1.0.2. [RUSTSEC-2026-0543](https://rustsec.org/advisories/RUSTSEC-2026-0543.html) marks every `chrono` version as unmaintained, with no patched version and no upgrade path, and names `jiff` as a recommended alternative. `jiff` is maintained, supports the Rust version this repository pins, and provides date and time parsing, formatting, time zones, and daylight saving time support, so Clio no longer depends on a crate without a maintainer.
