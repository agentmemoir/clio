A `CLIO_COMPLIANCE_SALT` override now has to hold at least 32 bytes and is refused with a configuration error when it is shorter, matching the length the deployment salt file has always been held to, because a short salt is guessable and makes the subject hashes recorded in the erasure journal guessable with it; an override of 32 bytes or longer is still accepted exactly as before and still wins over the salt file beside the journal, so a deployment that already sets one needs no change.
