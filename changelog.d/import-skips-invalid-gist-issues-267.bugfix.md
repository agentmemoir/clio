An import now reports the entity id and skips an entity whose stored gist exceeds the published length limit, instead of aborting the whole bundle: every other entity in the bundle still applies, and both the JSON report and the default text output name what was skipped and why. An import that restores nothing now says exactly that, with its created, overwrote, skipped, rejected, and skipped-as-invalid counts, and a dependent row whose carrier was skipped this way is announced as skipped, not as an admission rejection.
