`clio mcp http` now requires authentication on every bind, including loopback: with no `--token-file` the process refuses to start instead of serving unauthenticated, naming the token store and the new `--insecure-no-auth` opt-out. A request without a valid bearer token is refused with HTTP 401. [Issue #224](https://github.com/agentmemoir/clio/issues/224)
