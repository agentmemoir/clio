`clio mcp http` now requires authentication on every bind, including loopback: with no `--token-file` it mints a random bearer token and prints it once to stderr, and a request without that token is refused with HTTP 401. The new `--insecure-no-auth` flag restores the old credential-free loopback server for local development. [Issue #224](https://github.com/agentmemoir/clio/issues/224)
