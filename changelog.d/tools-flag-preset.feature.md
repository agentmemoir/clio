`clio mcp stdio` and `clio mcp http` now accept `--tools PRESET`, taking `minimal`, `coding`, `ops`, `all`, or `custom:GROUP[,GROUP]` to choose the tool groups the server advertises, where a custom list starts from the minimal set and adds the groups it names plus what they require; with no flag the `mcp.tool_profile` setting decides and, when it is unset, the minimal preset applies, and a value naming no preset or no known group stops the start with a usage error naming it instead of advertising a guessed set.
