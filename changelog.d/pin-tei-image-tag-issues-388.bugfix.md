The TEI embedding and rerank images are pinned to patch release 1.9.4 for both amd64 and arm64, so a new patch release cannot change behavior silently. The local NuExtract extract server image is pinned to llama.cpp build b12033, so a moving upstream tag cannot change extraction behavior silently. CI now runs the same Postgres image as the compose stack, `pgvector/pgvector:0.8.6-pg16`, so tests and local runs share one database build.
