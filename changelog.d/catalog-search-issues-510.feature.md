An MCP server can now expose a `tool_search` discovery tool when the deployment setting `mcp.discovery` is `true`; the setting is off by default, so a server that never sets it advertises the same tools as before. `tool_search` ranks the full tool catalog by lexical token overlap between the query and each tool's name and description, breaks ties by catalog order, returns 10 results by default, clamps a larger limit to 25, and accepts a `family` filter that narrows the search to one of the 17 tool groups.
