The MCP operator tools — `diagnose`, `verify`, `doctor`, `repair`, and `reindex` — resolve the caller's context once and gate every arm of each tool through one bank scope, so a principal bound to one bank gets a report scoped to that bank and an explicit `forbidden` error for a foreign bank, instead of the whole store's bank list and metrics, while a caller without a credential keeps whole-store reach.
