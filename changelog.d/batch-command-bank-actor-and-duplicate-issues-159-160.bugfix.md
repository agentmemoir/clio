The `batch` command now applies its command-level `--bank` and `--actor` to every operation that does not name its own, and it scores each operation against the operations already staged earlier in the same batch, so the batch matches the bank it would find after commit: an operation that repeats an earlier operation's stored text is rejected by the duplicate gate, and a near-duplicate that the novelty factor pushes below the threshold is rejected too, rolling the whole batch back unless that operation sets `allow_duplicate`.
