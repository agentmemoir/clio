A sync push now takes the apply lock of every authorized bank it writes item state to, not only of the bank its request body names: a mutation carries its own bank, and a denial carrier covers further banks, so two peers pushing under different request banks but into the same stored bank could previously interleave on that bank's memory row and let the older last-writer-wins stamp land last, leaving stale content in place; each push now locks the envelope bank, every mutation bank its credential may reach, and every covered bank it can record — including the covered banks of a sealed carrier, which are read from the content the serving peer opens — acquiring them in one sorted order so overlapping pushes cannot deadlock, while the one shared node-wide status slot stays outside the lock set so it never serializes every push.
