A sync push now takes the apply lock of every bank it can write, not only of the bank its request body names: a mutation carries its own bank, and a denial carrier covers further banks, so two peers pushing under different request banks but into the same stored bank could previously interleave on that bank's memory row and let the older last-writer-wins stamp land last, leaving stale content in place; each push now locks the envelope bank, every mutation bank, and every covered bank, acquiring them in one sorted order so overlapping pushes cannot deadlock.
